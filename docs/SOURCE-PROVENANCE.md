# Source provenance

This public repository is a curated source snapshot derived from the preserved private Agent Memory Atlas archive at commit `47cd29396d5373168b1f6db8e5af81f7f1ce3943`. It is not a reconstruction of earlier development history. The archive's earlier commits, tags, deployment records, and excluded operational materials are not part of this public repository.

The source combines a server-source import and a local research working copy captured on 3 November 2026. The public snapshot excludes the live corpus, private full texts, credentials, provider-generated datasets and the previously bundled font. The included demonstration corpus, its page passages, vectors and citation relationships are fictional.
